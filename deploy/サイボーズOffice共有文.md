# キャッシュフロー診断の試験運用とホームページ掲載のお願い

## 社内共有

- お客様が入力前に情報の取り扱いへ同意する画面を追加。
- 収入・支出・金融資産から診断し、奨学金や各種ローンは別欄で確認。
- 回答と診断結果をスプレッドシートに記録。同じ画面での修正は同じ行に反映。現在の版は **v1.6.3**。
- 現在は GitHub 上での試験運用。実際のお客様への案内は、本番用の設置と確認が完了してから。

## ホームページ管理者の方へのお願い

1. ホームページのサーバーに診断専用の場所を作成してください。例：公開フォルダ内の `cf`（公開URLの例：`https://自社ドメイン/cf/`）。実際のサーバーの公開フォルダ名はご確認ください。
2. お渡しする **`index.html` だけ**を `cf` 内に設置してください。ZIP一式や `gas/Code.gs` は公開しません。WordPress の固定ページ本文にHTMLを貼り付ける作業ではありません。
3. サーバーの「アクセス制限」機能で `cf` にパスワードを設定し、社員が案内したお客様だけが利用できる運用にしてください。HTTPSでも開けることを確認してください。
4. WordPress 側には、診断ページ `https://自社ドメイン/cf/` へのリンクを1本設置してください。
5. パスワード画面→同意画面→入力→診断結果まで開けるかご確認ください。スプレッドシートへの保存確認は当方で行います。

※ WordPress の管理画面だけではサーバー内にHTMLファイルを置けない場合があります。その場合は、サーバー管理画面・ファイル管理機能を使える方、または保守会社に上記1～3を依頼してください。

## 今後の修正・担当

- **質問文や画面の変更**：当方が新しい `index.html` を用意 → サーバー側の同じ場所のファイルを差し替え。URLとWordPressのリンクは原則そのまま。
- **診断基準や保存項目の変更**：当方がGASを更新・再デプロイ。画面も変わる場合だけ `index.html` も差し替え。
- 更新のたびに管理者へ依頼する手間を減らすには、可能であれば診断用フォルダだけを更新できる権限を当方に付与する方法もご相談ください。権限付与が難しければ、変更時に `index.html` の差し替えをお願いします。

## 本番公開前に確認すること

- 同意画面の会社名・問い合わせ先を正式な内容へ変更。
- 検証用の合言葉 `test` を変更し、GAS側も再デプロイ。
- 保存期間5年に対応する削除手順と、テスト回答を集計から除外する方法を決定。

入力画面のHTMLは利用者のブラウザへ配信されるため、閲覧可能です。診断の判定基準はGAS側に置いています。
